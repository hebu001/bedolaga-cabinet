## Визуальный baseline: требуется снять

На этом подготовительном этапе снимки не делались, браузер к аккаунтам и серверам не подключался. Следующий шаг — локальная сборка точного fork SHA с детерминированными fixtures, без реальных токенов, персональных данных и платежей. Mocked UI подтверждает вид и frontend-сценарии; он не доказывает работоспособность настоящей связки API/Telegram.

Для каждой записи сохранить viewport, browser/version, язык, фиксированное время, имя fixture, SHA и путь снимка. Начальные viewport: mobile 390×844 и desktop 1440×900; дополнительно узкий mobile 360×800 для overflow и переход через действующий breakpoint shell. Согласованные образцы после переноса сравниваются при тех же данных. Telegram/Web login проверяются отдельно на integration gate.

## Доказательства и пределы

Ранее выполненный аудит подтверждает 157/157 тестов точного fork snapshot, 11 suite в `npm test`. Это историческое свидетельство (`baseline-verification.json`, `fork-baseline-tests.log` рядом с audit), а не новый запуск, clean npm-ci или проверка результата слияния. Новая рабочая копия пока содержит неизменённые исходники baseline и эти документы. Столбец «не начат» меняется только после проверки конкретного перенесённого сценария.

Смена upstream `npm test` на Vitest не должна исключить 11 custom suite из CI. В будущей итоговой конфигурации нужны оба набора. `test:dependencies` и `test:nginx` — дополнительные проверки, не входящие в baseline `npm test`; nginx suite применять при соответствующем варианте публикации.

Bundle budgets baseline: initial raw 900000 / gzip 285000, userLocale raw 120000 / gzip 30000 байт. Известное прежнее превышение initial raw на 64 байта не разрешает поднять лимит. Измерение размера bundle не является измерением Web Vitals.
