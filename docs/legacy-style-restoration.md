Единственный визуальный источник: `codex/cabinet-ux-performance-20260906`, коммит `55a4038f4ae8692922abc2622f97309840f71064`. Новая логика/API сохраняется из версии 1.79.0. Предыдущий приблизительный вариант из коммита 48a10457 заменён.

Токены старой палитры ограничены соответствующими маршрутами и их модальными окнами. Новые пункты админки, выбор рекомендуемого периода, переход с прежней подписки на тариф, облегчённая витрина и новый сценарий пополнения сохраняют актуальную логику и используют старое оформление.

Проверены `/admin`, `/subscriptions/`, `/balance`, `/subscription/purchase`, `/subscription/purchase?renew=1`, `/subscription/purchase?renew=1&subscriptionId=34` на ширинах 390 и 1440 px. Все 12 открытий без ошибок JavaScript и горизонтального переполнения. Диалог «Изменить» открывается и закрывается клавишей Escape.

Скриншоты получены из реального React-приложения в Chrome с одинаковыми синтетическими ответами API для старой ветки и восстановленной версии. Это локальная проверка интерфейса, а не авторизованная проверка реального сервера. Баланс, тарифы и статистика на скриншотах — тестовые данные. Весь внешний трафик заблокирован; POST запроса WebSocket ticket отклонён локально; запросов оплаты и изменения подписок нет.
