# Восстановление интерфейса кабинета по старой ветке

Единственный визуальный источник: `codex/cabinet-ux-performance-20260906`, коммит `55a4038f4ae8692922abc2622f97309840f71064`. Новая логика/API сохраняется из версии 1.79.0. Предыдущий приблизительный вариант из коммита 48a10457 заменён.

Перенесены исходная разметка админки и тарифной формы, карточки витрины, диалог выбора тарифа, палитра, разделители, размеры, скругления, отступы и рисунки навигации. Токены старой палитры ограничены соответствующими маршрутами и их модальными окнами. Новые пункты админки, выбор рекомендуемого периода, переход с прежней подписки на тариф, облегчённая витрина и новый сценарий пополнения сохраняют актуальную логику и используют старое оформление.

Проверены `/admin`, `/subscriptions/`, `/balance`, `/subscription/purchase`, `/subscription/purchase?renew=1`, `/subscription/purchase?renew=1&subscriptionId=34` на ширинах 390 и 1440 px. Все 12 открытий без ошибок JavaScript и горизонтального переполнения. Диалог «Изменить» открывается и закрывается клавишей Escape.

Скриншоты получены из реального React-приложения в Chrome с одинаковыми синтетическими ответами API для старой ветки и восстановленной версии. Это локальная проверка интерфейса, а не авторизованная проверка реального сервера. Баланс, тарифы и статистика на скриншотах — тестовые данные. Весь внешний трафик заблокирован; POST запроса WebSocket ticket отклонён локально; запросов оплаты и изменения подписок нет.

Проверки: TypeScript; 36 Vitest-тестов (оплата/пополнение, прежние подписки, облегчённая витрина, навигация админки, котировки); 18 регрессий оплаты; 4 регрессии админки; production build и бюджет JavaScript: 892495 bytes raw, 284228 bytes gzip. Оплата и платное продление не выполнялись.

На сервер этот вариант не опубликован: пользователь сначала запросил просмотр страниц. Подготовленный ранее изолированный релиз 48a10457 не является актуальным результатом и не должен публиковаться.

## Внутренние разделы админки

Восстановлены рисунки SVG из старой ветки, оформление кнопки возврата, карточки статистики, цвета и модальные окна внутренних разделов. В том числе: дашборд, платежи, промокоды, кампании, партнёры, серверы, тикеты, рассылки, роли, политики, новости. Для новых разделов версии 1.79.0 (купоны, grace access, напоминания, юридические страницы, системные ошибки, проверка доступности и уровни наград) применены существующие цвета и элементы старой ветки. API, обработчики изменений и ограничения доступности функций сохранены.

По последним указаниям пользователя **список пользователей `/admin/users`, статистика продаж `/admin/sales-stats`, весь раздел тарифов `/admin/tariffs` (список, создание, редактирование), Remnawave `/admin/remnawave` (включая сквады и внутренние окна) и настройки `/admin/settings` (вкладки и внутренние окна) оставлены в новом варианте**: файлы страниц и дочерние компоненты совпадают с исходным состоянием до этих изменений. Общая кнопка возврата сохраняет для них новую форму и SVG; старые токены не применяются к странице и её порталам. Переходы dashboard → users → sales-stats → tariffs → tariffs/create → dashboard проверены: классы старой палитры корректно снимаются и возвращаются.

Локальная браузерная проверка: 90 шаблонов маршрутов × 2 размера (390 и 1440 px), 180 открытий без ошибок JavaScript и переполнения ширины документа. Горизонтально прокручиваемые таблицы и панели вкладок сохранены. В некоторых маршрутах есть переадресация в основной раздел. Данные синтетические, сетевые ответы подменены только в проверочном скрипте. Закрытые контрактом новые разделы просмотрены с временной подменой флагов только внутри браузерной проверки; исходный `integrationCapabilities.ts` не изменён. Это не проверка авторизованных операций на тестовом сервере.

Проверки: 110 файлов / 588 тестов админки; после возврата пользователей и статистики продаж повторно 7 файлов / 82 теста пользователей и навигации. После возврата тарифов повторно прошли 11 тестов кнопки возврата. Финальная сборка TypeScript/Vite прошла; бюджет initial JS: 879782 bytes raw, 281123 bytes gzip. Публикация не выполнялась. Подробные маршруты и снимки: `../cabinet-admin-style-20260929/RESULT.md`.

После возврата Remnawave дополнительно прошли 45 тестов навигации/geo-check, повторная сборка и бюджет JS. Remnawave и карточка сквада проверены на 390/1440 px; их страницы и компоненты внутренних окон совпадают с состоянием до восстановления старого оформления.
