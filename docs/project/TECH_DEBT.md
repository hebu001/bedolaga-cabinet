# TECH DEBT — Bedolaga Cabinet

## Критический (P0)

### TD-001: App.tsx — GOD file
- **Описание**: Весь роутер в одном файле, 1173 строки, 95+ импортов страниц
- **Риск**: Любая ошибка роняет всё приложение; сложность навигации; конфликты в git
- **Сложность исправления**: ВЫСОКАЯ (нужна поэтапная разбивка на route groups)
- **Ожидаемый эффект**: Улучшение DX, уменьшение конфликтов, лучшая читаемость

### TD-002: Нет тестов
- **Описание**: Ни unit, ни integration, ни e2e тестов не обнаружено
- **Риск**: Любой рефакторинг может сломать незамеченные вещи
- **Сложность исправления**: ВЫСОКАЯ (нужно писать с нуля)
- **Ожидаемый эффект**: Безопасный рефакторинг, онбординг новых разработчиков

## Высокий (P1)

### TD-003: AdminUserDetail.tsx — 114KB
- **Описание**: Самая большая страница, god component
- **Риск**: Тяжёлая производительность, сложность сопровождения
- **Сложность исправления**: СРЕДНЯЯ
- **Ожидаемый эффект**: Лучший TTI, легче вносить изменения

### TD-004: refreshToken в localStorage
- **Описание**: refreshToken хранится в localStorage, доступен из JS
- **Риск**: XSS может украсть refresh token
- **Сложность исправления**: СРЕДНЯЯ (нужна координация с backend на HttpOnly cookie)
- **Ожидаемый эффект**: Устранение класса XSS атак

### TD-005: nginx.conf — неправильная конфигурация /api/
- **Описание**: В nginx.conf внутри Docker есть попытка проксировать /api/ с try_files вместо proxy_pass — это неработающий код
- **Риск**: Если cabinet_frontend запустить как контейнер, /api/ не будет работать
- **Сложность исправления**: НИЗКАЯ (исправить nginx.conf)
- **Ожидаемый эффект**: Правильная работа container-based варианта деплоя
