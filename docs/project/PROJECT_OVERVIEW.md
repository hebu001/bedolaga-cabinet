# PROJECT OVERVIEW — Bedolaga Cabinet

## Что это

**Bedolaga Cabinet** — веб-кабинет (личный кабинет пользователя + панель администратора) для VPN-сервиса на базе Telegram-бота **Remnawave Bedolaga**.

- **Тип**: Frontend-only SPA (React + Vite + TypeScript)
- **Роль в системе**: Веб-интерфейс для управления VPN-подпиской
- **Backend**: Внешний — `remnawave-bedolaga-telegram-bot` (недоступен в этом репозитории)
- **Production URL**: `https://miniapp.evovpn.ru`

## Что умеет пользователь (user flow)

- Вход через Telegram WebApp / Telegram Widget / Email / OAuth (Google, Yandex, Discord, VK)
- Просмотр статуса подписки, трафика, дней
- Покупка/продление/смена тарифа (режимы: classic, tariffs)
- Пополнение баланса (несколько платёжных методов)
- Реферальная программа
- Колесо удачи, конкурсы, опросы
- Поддержка (тикеты или ссылка на оператора)
- Профиль, привязка аккаунтов (TG, OAuth), смена email

## Что умеет администратор (admin flow)

- Панель статистики (AdminDashboard)
- Управление пользователями, их подписками, банами
- Управление тарифами, серверами
- Система платежей и способов оплаты
- Рассылки, закреплённые сообщения
- Промокоды, промо-группы, кампании
- Партнёрская программа, выплаты
- Колесо удачи (настройки)
- Remnawave интеграция (серверные группы/squads)
- Email-шаблоны
- RBAC: роли, политики, назначение ролей
- Журнал аудита
- Лендинги (встроенный редактор)
- Подписные каналы
- Статистика трафика, продаж
- Тикеты поддержки
